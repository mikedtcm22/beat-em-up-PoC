## Effects (VFX)

The comic effect set (Spec §6 and §10, "2D effects"; Milestone 2). Claude drew every piece as SVG with `tools/gen_fx.gd` (shapes from a seeded random generator; the lettering uses an original block alphabet defined in that script, no font outlines). The same script rasterizes each SVG to a 512 px PNG (long side, transparent) with Godot's built-in SVG rasterizer. Redraw and re-export with `godot --headless -s tools/gen_fx.gd`, then `godot --headless --import --quit`; after editing an SVG by hand, add `-- --raster-only`. Red is used only for blood, the rear-warning burst and finisher accents (Spec §10).

Milestone 4's final pass (package P1-fx) redrew the set in one ink (`#120f17`, the toon hull's and the HUD's), with the main strokes at about twice the character hull (`INK_TABLE` in the script ties each effect's stroke to its size on screen), Ben-Day dots drawn as explicit circles on the bursts and the lettering, a second variant of each burst tier (`_2`), lettering drawn to one cap height (every word is the same number of cap heights wide) with an inner highlight, and blood outlined in ink. The art is seeded and byte-stable: a rerun of the script leaves every SVG and PNG unchanged (`godot --headless -s tools/gen_fx.gd -- --out=<dir>` writes a copy for comparing; `tests/test_fx_m4.gd` does).
