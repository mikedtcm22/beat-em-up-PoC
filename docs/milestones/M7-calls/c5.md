# C5: the drawn cards (cut-ins), Milestone 7 Phase 3

Built to the table in [M7-comic-3d.md](../M7-comic-3d.md), "The drawn cards". The art comes in the next task; placeholders (flat colour with the card's name, 1600x900) ship now.

## What is where

- `game/ui/cut_in.gd` (`CutIn`): a full-screen Control, built by `GameHud._ready()` as its topmost child and advanced last in `GameHud.advance()` (game time, so a pause holds it).
- `game/ui/cut_in_set.gd`, `game/ui/cut_in_entry.gd`: the data. `game/ui/cut_ins/mission1.tres` maps events to textures; `assets/export/ui/cut_ins/` holds `title`, `punk_entrance`, `ko_punk_1`, `ko_punk_2`, `mission_end` (placeholders).
- `TimeController.hold_sim(source, on)` / `is_sim_held()`: the one new API. `sim_scale()` (so `scale_for()`) returns 0 while any source holds; it is not a pause (`GameInput.paused` stays false). `clear()` drops all holds; a freed CutIn lets go.
- Tunables, group "Cut-ins (M7)" (before "Debug"): `cutins_enabled`, `cutin_title_hold_s` 1.5, `cutin_entrance_hold_s` 0.9, `cutin_ko_hold_s` 0.5, `cutin_end_lock_s` 0.5, `cutin_fade_s` 0.1, `cutin_lettering_size`. `tuning/default.json` regenerated.

## Triggers

| Card | Trigger in code | Notes |
|---|---|---|
| Title | first `advance()` after `_ready()` when a `level_root` node exists | rooms without a level have none |
| Entrance | `get_tree().node_added` for an `EnemyActor`, read once the enemy is ready (the Punk names its `archetype` in `_ready()`), once per archetype per mission | Ox is `boss`: his card fires when he enters the tree, which is the boss intro (`boss_phase_changed` only fires at phase 2) |
| Knockout | `arena_cleared`, once per arena, entry of the archetype of the last `ko` victim; `pick(n)` turns through that entry's textures | dropped when another card is up or waiting |
| End | `level_cleared`; held until punch, kick, back attack, grab or ui_accept, which are ignored for `cutin_end_lock_s` | |

Any of those five inputs skips a card (consumed, the next waiting card starts). Cards queue (3 waiting at most; the end card always queues). A card with no texture, or an entry that is missing, is skipped silently: Thug, Bruiser, Kicker and Ox have entries and lettering but no art yet. Lettering (label, sub label, the end prompt) is drawn over the art in `HudStyle`'s bold comic font on a paper panel; knockout panels carry none.

Off: under the `m6` profile, or with `cutins_enabled` off, no card is queued, and a card up when the profile flips goes down. Tests start in m6.

## To add the art

Assign textures in `game/ui/cut_ins/mission1.tres` (an entry's `textures`); the label is already there. A new enemy type needs one `CutInEntry` with its archetype as `key`.

## Bot and record command

`tests/bot/cut_in_bot.tscn` plays the street start under the trailer profile with cards on (waves off, AI frozen): title, Punk entrance skipped by a punch, a second Punk and a Thug (no card), two arena clears (two panels), Ox (silent), mission end held until a kick. It prints `C5-BOT` PASS/FAIL lines and the sim scale while each card is up.

```
tools/capture_bot.sh res://tests/bot/cut_in_bot.tscn captures/m7-comic/c5 "" 3
godot --headless --fixed-fps 60 --quit-after 3000 res://tests/bot/cut_in_bot.tscn           # checks only
godot --headless --fixed-fps 60 --quit-after 3000 res://tests/bot/cut_in_bot.tscn -- --profile=m6   # cards off
```
