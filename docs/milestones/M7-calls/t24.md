# T24: trailer frame time (perf3)

Gate: trailer within +10% of m6 on the Mission 1 level walk. At 7f8528a it was +9.7% (m6 10.93 ms, trailer 11.99); now **-6.9%** (m6 10.90, trailer 10.15), interleaved, 4 runs each, vsync on. Reports and the per-feature table are in `captures/m7-slice/perf3/` (`report.txt`, `features.txt`; not committed).

Where the time went (trailer features switched off one at a time, single runs, noise about 0.05 ms): painted sky 1.31 ms, bloom 0.94, haze quad 0.64, edge finish shader 0.52, lamp OmniLights 0.33, painted characters 0.13, all the cards together 0.14 (overdraw is not the cost). The 0.85 finish scale saves 2.2 ms by itself.

Cuts:
- `TrailerLook._tick_sky` wrote about ten sky uniforms every physics tick. A written sky material counts as a changed sky, so the radiance map and the ambient light from it were re-rendered each frame. `_write_sky` now writes only what moved (-1.30 ms, no visual change).
- `haze_band.gdshader`: the band noise runs only where the wobbled distance can reach a band start, and the mist noise only below its wobbled top (exact early-outs). `edge_pass.gdshader` (finish only): the line-break noise runs only on pixels with a line. Together -0.26 ms, pixel-identical.
- `project.godot`: `rendering/environment/glow/upscale_mode=0` (linear, was bicubic). Only a glow-enabled environment reads it (trailer profile; m6 has glow off). -0.21 ms; the bloom differs by at most 19/255 around the lamps.

Not done, if more is wanted: the 4 lamp OmniLights (0.33 ms; energy 0.12, so a lamp's visible effect is small, but removing them changes the paint), glow level 4, a baked noise for the finish shift.
